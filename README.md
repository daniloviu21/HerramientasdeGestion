# HerramientasdeGestion
Herramientas de gestión de proyectos y de recursos: repositorios de código y documentación

AutiSense es una plataforma tecnológica innovadora diseñada para la detección temprana de señales de riesgo del Trastorno del Espectro Autista (TEA) en infantes, utilizando técnicas de Inteligencia Artificial y Visión por Computadora.  
El proyecto busca solucionar la problemática del diagnóstico tardío ofreciendo una herramienta de tamizaje accesible y objetiva para familias, educadores y profesionales de la salud.
